# pokeemerald-expansion

This is a personal modification of Pokémon Emerald focused on improving AI behaviour and overall battle difficulty while staying close to the original game.

Features:
- Improved AI decision-making
- Trainer changes
- General balance adjustments
- Up to Gen 9 mechanics
- Qol features (Instant Text, Pokevials, HMs work from bag)
- Altered Pokemon stats, abilities and moves

Note:
- Designed for male player character only
- Debug menu is still present (press R) — please avoid using it except for Pokévials or Fly if needed
- EXP system similar to Emerald Rogue (max EXP on KO up to level cap)
- No EVs
- This is an early playtest build, not fully polished

Instructions:
1. Use a clean Pokémon Emerald ROM
2. Apply the .ups patch using NUPS
3. Play on mGBA or VBA-M
